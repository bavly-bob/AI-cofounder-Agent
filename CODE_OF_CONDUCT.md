# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, without changes, as its code of conduct. The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we pledge to make participation in this community a harassment-free experience for everyone, and we expect everyone who takes part in this project's spaces (issues, pull requests, chat) to follow it.

## Reporting

Report unacceptable behaviour to the project maintainers by opening a GitHub issue on this repository, or privately through GitHub's "Report content" option on the comment or issue concerned. All reports will be reviewed promptly and fairly, and the privacy of the person reporting will be respected.
